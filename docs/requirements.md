# 말랑말랑 (ship and giggle) — 요구사항 정의

> 기준: 디자인 캔버스 **「말랑말랑 — 발음 연습 앱」** (보드 87개, 2026-11-08 ~ 11-10 작업본).
> 요구사항 문서(프로젝트 지시서)와 디자인이 다른 곳은 아래 "결정 사항"에 근거와 함께 적었다.

## 1. 서비스 한 줄 정의

**자기 말소리를 눈으로 보며** 자음·모음 발음을 연습하는 독립 학습 서비스.
점수 대신 **실제로 잰 사실**만 보여주고, **정답(목표 발음)과 비교**하며, **내 이전 녹음과만 비교**한다.

## 2. 결정 사항 (2026-11-10 사용자 승인)

| 항목 | 지시서 | 디자인 | 결정 |
|---|---|---|---|
| 백엔드 | NestJS | FastAPI | **NestJS(API·인증·DB) + Python 분석 워커** |
| 역할 | 아동·보호자·치료사·관리자 | 학습자·듣는 사람 | **디자인대로**: 학습자, 로그인 없는 듣는 사람, 만 14세 미만 보호자 동의, 콘텐츠 관리자 |
| 관리자 페이지 | 필요 | 화면 없음 | **기존 디자인 톤으로 간단히** (단어·문장 등록/수정/검토, 신고 목록) |
| 앱 | 반응형 웹 | Expo 앱 + 웹 | **반응형 웹 먼저** (디자인의 개발 순서 1단계와 같음). 앱 화면은 웹 모바일 화면으로 구현 |
| 의료 표현 | "치료" | "진단·치료 표현은 검증 전 쓰지 않음" | 화면 문구는 디자인대로 ("진단"은 디자인 화면에 있는 그대로만) |

## 3. 사용자

- **학습자**: 본인 계정으로 진단·연습·기록. 로그인 없이 진단만 먼저 해볼 수 있음(게스트) → 기록 저장 전 가입.
- **보호자**: 만 14세 미만 학습자 가입 시 법정대리인 동의(이름·연락처·동의 시각) 기록.
- **듣는 사람**: 학습자가 만든 링크로 가입 없이 녹음을 듣고 받아쓰기. 정답을 미리 보지 않음.
- **관리자**: 테스트 단어·문장 등록·수정·검토 승인, "결과가 이상해요" 신고 확인.

## 4. 기능 요구사항

### 4.1 계정 (디자인: Login, IdLogin, SignUp, 로그인 예외 메모)
- F-AUTH-1 아이디 회원가입: 아이디 중복 즉시 확인, 비밀번호 8자 이상·영문·숫자 포함, 비밀번호 확인 일치, 이름, 약관·개인정보 동의 필수.
- F-AUTH-2 아이디 로그인: 틀리면 "아이디 또는 비밀번호가 맞지 않아요"(어느 쪽인지 밝히지 않음), 5번 틀리면 10분 잠금, 남은 횟수 표시.
- F-AUTH-3 카카오·구글 로그인(OAuth). 키가 설정되지 않으면 버튼이 "준비 중" 안내.
- F-AUTH-4 로그인 없이 진단 → 게스트 계정, 가입 시 기록 이어받기.
- F-AUTH-5 JWT 액세스 토큰(15분) + 회전형 리프레시 토큰(30일, DB에 해시 저장).

### 4.2 시작 준비 (MicPermission, MicDenied, MicCheck)
- 녹음 전 목소리 녹음 동의 기록(무엇에 쓰는지 고지).
- 마이크 권한 요청·거부 안내.
- 주변 소음 측정, 평소 목소리 "아——" 3초 → **기준 목소리**(크기·높이) 저장.

### 4.3 첫 진단 (PlacementIntro~Result)
- 글자 23(자음 13 + 모음 10) → 단어 8 → 문장 3.
- 말하면 **들린 그대로** 글자로 보여줌(자동 보정 없음).
- 글자·단어·문장을 모두 통과한 소리는 처음부터 클리어("이미 발음이 좋아요", 초록).
- 건너뛰기 가능("아직 어려워요").

### 4.4 하루 목표 (GoalSetup, Settings)
- 3 / 5(추천) / 10개, 알림 시간(아침 8·점심 12·저녁 8 또는 없음), 진동·화면 알림.

### 4.5 오늘의 학습 (Main, Learn, Record, Result, RecordSentence, Complete, Review, Diary)
- 홈: 연속 기록, 오늘 녹음 수, 클리어 소리 수, 연습 순서 바, 오늘 진행(n/목표), 이번 주 7일, 학습 경로(완료·이미 좋음·지금·잠김).
- 소리 배우기: 소리 나는 곳·내는 방법·목 떨림, 단계 설명, 비슷한 소리와 차이.
- 따라 말하기: **녹음해야 다음으로** 넘어감. 녹음 중 크기 막대·쉬익 미터(기기 계산).
- 결과: 정답 vs 실제로 낸 소리, 한 소리씩 비교(통과/바뀜/빠짐/더해짐/확실 X), 목소리 상태(크기·높이·빠르기), 응원 한 줄 + 고칠 것 하나.
- 녹음 문제 5가지(작음·시끄러움·짧음·깨짐·다른 말) 감지 시 점수 없이 고칠 것 안내, 횟수에 안 셈.
- 3번 연속 어려우면 도움 시트.
- 완료: 오늘 말한 횟수, 목표 달성, 연속 일수, 한 줄 일기.

### 4.6 기록 (Records, Progress, EmptyRecords)
- 소리별 처음 녹음과 최근 녹음 비교, 이번 주 녹음 수, 자음정확도(PCC)·낱말 정확도(PWC) — 같은 단어 목록으로만.

### 4.7 사람 귀 확인 (ListenerShare, WebListen, ListenerResult)
- 녹음을 골라 7일짜리 받아쓰기 링크 생성, 듣는 사람 유형(가족·친구·선생님·처음 듣는 사람).
- 듣는 사람: 들은 대로 적기 / 잘 모르겠어요, 들어본 정도(처음·가끔·자주). 정답은 끝난 뒤 공개.
- 학습자: 사람 귀 vs 앱 비교.

### 4.8 개인정보 (TechSpec 6장)
- 녹음은 민감 정보: 첫 녹음 전 동의, 서버에 **AES-256-GCM 암호화** 저장, 보관 기간(기본 90일) 지나면 원본 자동 삭제(결과 글자·측정값만 남김).
- 내 녹음 전부 지우기, 계정 삭제 시 전부 삭제.
- 녹음 파일은 본인 인증 요청으로만 재생(공개 URL 없음).
- 모델 개선·연구용 사용은 별도 선택 동의.

### 4.9 연습 더하기 (Baseline, WeeklyCheck, Review, StreakLost, VoiceForward, EndClear, Intonation, Timing, SMeter, SoundTextures, Vowels, VowelSpace)
- 새 소리 시작 전 기초선: 단어 3개 × 3번, 피드백 없음. 일주일 뒤 같은 단어로 다시 녹음해 기초선과만 비교(들린 대로 기준).
- 복습 3개: 배웠거나 이미 좋은 소리 중 오래 안 본 것부터. 이틀 넘게 쉬면 탓하지 않는 ‘다시 만나서 반가워요’ + 목표 줄이기.
- 발성·억양: 목소리 앞으로(처음 기준 목소리 대비 울림 위치·거리), 끝소리(글자별 크기), 묻는 말 끝 올리기(끝 높이 변화), 길게 끌지 않기(글자 길이·빠르기). 점수 없이 잰 값만.
- ㅅ 쉬익 미터(바람 중심 kHz, 목표 6~8.5), 소리 모양 사전(진동 패턴), 모음 입모양 10(애니메이션), 내 모음 삼각형(ㅣ·ㅏ·ㅜ 넓이, 처음=100).

### 4.10 내 글로 연습 (MyScript, MyScriptResult, Web*)
- PPT·PDF·사진(OCR)·붙여넣기 원고 → 슬라이드 범위 → 읽으면서 녹음 또는 녹음 파일 → 문장별 달라진 발음·건너뜀·원고에 없는 말·끝소리·빠르기 흐름. 달라진 단어로 바로 연습. 원고는 언제든 지움.

### 4.11 설정 더하기 (VoiceModel, ResearchMode, WebSettings, Offline)
- 내 목소리에 맞추기(기본 꺼짐, 켜면 동의 기록, 끄면 개인 기준 삭제) · 녹음 원본 보관 30일/90일/1년/내가 지울 때까지.
- 연구 모드 · 녹음 원본 포함 · 심의 번호 · 기록 내보내기(CSV zip).
- 웹 푸시 알림, 진동, 큰 글자. 계정 연결(카카오·구글), 비밀번호 바꾸기, 이메일 인증 → 이메일로 비밀번호 재설정.
- 인터넷이 끊기면 녹음을 기기에 보관 → 연결되면 자동 업로드.

### 4.12 관리자
- 단어·문장 목록, 등록·수정·삭제, 표준 발음(정답) 입력, 검토 승인(검토자·검토 시각), 신고 목록.

## 5. 분석 요구사항 (가짜 결과 금지)

| 화면에 보이는 것 | 실제 계산 | 상태 |
|---|---|---|
| 들린 대로 | 한국어 음성 인식(sherpa-onnx Zipformer, 언어모델 없음) 결과 그대로 | 구현 |
| 정답 음소 | 표준발음법 규칙 엔진(연음·비음화·유음화·경음화·격음화·구개음화·ㅎ 탈락·받침 대표음) + 검토 고정본 | 구현 |
| 한 소리씩 비교 | 정답 음소 vs 들린 음소 편집거리 정렬, 허용 발음(ㅐ=ㅔ 등) | 구현 |
| 확실 X | 인식 토큰 구간이 0.06초보다 짧거나 인식 결과 없음 | 구현 (GOP-SF는 미구현) |
| 녹음 문제 5가지 | 음량·잡음 비율·말소리 길이·잘림·정답과 차이 | 구현 |
| 크기·높이·빠르기 | Praat(parselmouth) 음량·피치, 음절/초, 기준 목소리와 비교 | 구현 |
| 쉬익 미터 | 4kHz 위 에너지 비율 + 스펙트럼 중심 | 구현 |
| 모음 점(F1·F2) | Praat 포먼트 | 구현 |
| 끝소리 작아짐 | 마지막 음절 음량 vs 평균 + 끝 20% 구간 음량 | 구현 |
| 글자별 크기·길이 | 음량 곡선의 음절 핵(peak) 검출 → 글자 수와 맞으면 글자 이름을 붙임 | 구현 |
| 묻는 말 끝 올리기 | 마지막 구간 피치 기울기(반음), 내 평소 높이 기준 | 구현 |
| 목소리 앞으로 | 1~3kHz 대 0~1kHz 울림 비율을 처음 기준 목소리와 비교 | 구현 (기준 없으면 비교 안 함) |
| 실시간 모음 점 · 쉬익 미터 | 기기에서 LPC 포먼트 · 4kHz 위 에너지 중심 (표시용, 저장값은 서버가 다시 잼) | 구현 |
| 받아쓰기 교차 확인 | 목표 ㅅ·ㅆ인데 녹음의 4kHz 위 바람 구간이 거의 없거나 중심이 4kHz 미만이면 ‘같음’을 ‘확실하지 않음’으로 | 구현 |
| 원고 맞춤 | 긴 녹음을 나눠 인식 → 원고 글자와 정렬 → 단어별 같음·달라짐·건너뜀 | 구현 |
| 내 목소리에 맞추기 | 맞게 낸 모음(모음별 3번 이상)의 F1·F2 중앙값으로 목표 칸 이동 | 구현 (인식 모델 재학습 아님) |

**한계(화면·문서에 명시)**: 인식 모델은 일반 한국어 받아쓰기용이라 실제 단어로 기우는 경향이 있다. 음소 단위 CTC 모델 + GOP-SF로 교체할 수 있게 인식기 인터페이스를 분리했다.

## 6. 비기능
- 반응형: 390px 휴대폰 ~ 1440px 데스크톱.
- 접근성: 터치 영역 44px 이상, 텍스트 대비 4.5:1, 소리 대신 진동·화면.
- 분석 목표 시간: 단어 2초.
